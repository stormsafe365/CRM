# StormSafe CRM — Desktop App Download

Packaged Windows app (build: Aug 19, 2026). Split into two parts because GitHub caps files at 100 MB.

## How to install on a new laptop

1. Download all 3 files into the **same folder** (e.g. Downloads):
   - `StormSafe-CRM.zip.part1`
   - `StormSafe-CRM.zip.part2`
   - `JOIN-AND-EXTRACT.bat`
2. Double-click `JOIN-AND-EXTRACT.bat`. It rejoins the parts and extracts the app.
3. Open the extracted `StormSafe CRM-win32-x64` folder and run **StormSafe CRM.exe**.
4. Right-click the exe → Send to → Desktop (create shortcut) for a desktop icon.

Data is live from Supabase — every machine sees the same leads and quotes.
